# Definition of Done — Operations

Operations の各取り組みの完了基準。

## CI/CD パイプライン

- [ ] PR に対して lint / test / security が自動実行される
- [ ] main マージで staging に自動デプロイされる
- [ ] デプロイ失敗時に通知が届く
- [ ] マイグレーションが自動実行される (ゼロダウンタイム手順)

## 監視・アラート

- [ ] 必須メトリクス 4 項目のアラートが設定されている
- [ ] 構造化ログが本番環境で出力されている
- [ ] エラートラッキング (Sentry 等) が設定されている
- [ ] Runbook が P0 / P1 インシデントに対して用意されている

## セキュリティ

- [ ] `brakeman` / `bundler-audit` が CI で通過している
- [ ] OWASP Top 10 に対する `/security-review` を実施済み
- [ ] 本番の secrets が git 履歴に含まれていない
- [ ] 金融データへのアクセスログが記録されている

## パフォーマンス

- [ ] API p95 レイテンシが 200ms 以下
- [ ] N+1 クエリが検出されていない (bullet gem)
- [ ] DB インデックスが適切に設定されている

## ドキュメント

- [ ] 本番デプロイ手順が `docs/runbooks/deploy.md` に記載されている
- [ ] ロールバック手順が文書化されている
- [ ] オンコール担当者が定義されている
