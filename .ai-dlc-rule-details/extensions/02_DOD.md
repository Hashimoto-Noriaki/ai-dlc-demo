# Definition of Done — Extensions

Extensions 作業 (新コンテキスト追加 / 既存拡張) の完了基準。

## 新 Bounded Context 追加

- [ ] Context Card が `docs/domain/` に作成されている
- [ ] Context Map が更新されている
- [ ] 用語集 (Ubiquitous Language) に新コンテキストの用語が追加されている
- [ ] 既存コンテキストへの影響調査が完了し、文書化されている

## コード品質 (Construction の DoD に加えて)

- [ ] 新コンテキストのテストカバレッジ ≥ 80%
- [ ] **既存テストが全て通過している** (リグレッションなし)
- [ ] 既存コンテキストへの直接依存がない (ACL を介している)

## データベース

- [ ] マイグレーション安全性チェックリストを通過している
- [ ] 既存データへの影響がゼロか、データ移行スクリプトが用意されている
- [ ] staging 環境で本番相当のデータ量でマイグレーションを実行済み

## API

- [ ] 後方互換性が維持されている (既存クライアントが動作する)
- [ ] 変更がある場合 `CHANGELOG.md` が更新されている
- [ ] 非推奨化した API に適切なレスポンスヘッダーがある (`Deprecation`, `Sunset`)

## ドキュメント

- [ ] 変更に伴う ADR が作成されている (方針変更がある場合)
- [ ] API ドキュメントが更新されている

## デプロイ

- [ ] マイグレーションが前後どちらのアプリバージョンでも安全に実行できる
- [ ] ロールバック手順が文書化されている
