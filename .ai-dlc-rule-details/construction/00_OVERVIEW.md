# Construction フェーズ

## 目的

Inception で定義したドメインモデルとアーキテクチャに基づき、機能を反復的に実装する。

- Bounded Context 単位で機能を積み上げる
- AI とペアプロしながらコードを生成・レビューする
- テストを先に書き、品質を担保する
- 各スプリントで動くソフトウェアをデリバリーする

## 開発サイクル (1 スプリント)

```
1. タスク分解 (AI 支援)
   └─ ユーザーストーリー → 技術タスクに分解

2. 設計 (AI 支援)
   └─ シーケンス図 / クラス設計の叩き台を AI が生成

3. TDD 実装
   └─ テスト先行 → AI がプロダクションコードを生成 → 人間がレビュー

4. PR & レビュー
   └─ AI が /code-review → 人間が最終承認

5. マージ & デプロイ
   └─ CI 通過 → staging 自動デプロイ
```

## 主な成果物

| 成果物 | 担当 | 保存先 |
|--------|------|--------|
| プロダクションコード | AI (人間レビュー) | `app/` |
| テストコード | AI (人間レビュー) | `spec/` |
| マイグレーション | 人間 + AI | `db/migrate/` |
| API ドキュメント | AI 自動生成 | `docs/api/` |
