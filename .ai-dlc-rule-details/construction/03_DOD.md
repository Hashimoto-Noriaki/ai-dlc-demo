# Definition of Done — Construction (スプリント単位)

各 PR / スプリントは以下をすべて満たしたときに完了とする。

## コード品質

- [ ] RSpec が全て通過している (`bundle exec rspec`)
- [ ] テストカバレッジ ≥ 80% (SimpleCov)
- [ ] TypeScript エラーが 0 (`tsc --noEmit`)
- [ ] Linter エラーが 0 (RuboCop / ESLint)
- [ ] セキュリティスキャンが通過 (`brakeman` / `bundle audit`)

## アーキテクチャ

- [ ] ドメインロジックが集約 / Service に閉じている
- [ ] コントローラーがユースケースの呼び出しのみ行っている
- [ ] コンテキスト間の直接 AR 参照がない
- [ ] N+1 クエリがない (`bullet` gem で確認)

## テスト

- [ ] ハッピーパスのテストがある
- [ ] バリデーションエラーのテストがある
- [ ] 認可エラー (403) のテストがある
- [ ] API レスポンスの型テストがある

## ドキュメント

- [ ] API の変更があれば `docs/api/` が更新されている
- [ ] 複雑なビジネスロジックにコメントがある (WHY のみ)

## フロントエンド

- [ ] ブラウザで動作確認済み (ゴールデンパス)
- [ ] エラー状態の UI が実装されている
- [ ] レスポンシブ対応 (モバイル確認)

## フェーズ完了 (Construction 全体)

- [ ] MVP として定義した全ユーザーストーリーが実装されている
- [ ] staging 環境で本番相当のデータで動作確認済み
- [ ] パフォーマンス基準 (API p95 < 200ms) を満たしている
