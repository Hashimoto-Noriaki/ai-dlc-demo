# Definition of Done — Inception

Inception フェーズは以下をすべて満たしたときに完了とする。

## ドメイン設計

- [ ] Bounded Context マップが作成され、全コンテキストに名前がついている
- [ ] 各コンテキストの目的と主要集約が定義されている
- [ ] Context 間の依存関係 (Upstream/Downstream) が明記されている
- [ ] 用語集 (Ubiquitous Language) に 20 語以上が定義されている

## アーキテクチャ

- [ ] 必須 ADR がすべて Accepted ステータスになっている
- [ ] 技術スタックが確定している (Rails / Next.js バージョン含む)
- [ ] ディレクトリ構成のスケルトンが存在する

## プロジェクト基盤

- [ ] リポジトリが作成され、基本的な CI が動作している
- [ ] CLAUDE.md にプロジェクト概要と AI への作業ルールが記載されている
- [ ] `.ai-dlc-rule-details/` の全フェーズルールが初版として整備されている

## ゲートレビュー

- [ ] ドメインモデルをステークホルダーがレビューし承認した
- [ ] Construction フェーズの最初のスプリントバックログが作成されている
